# PROMPT-LOGIC
Here I developed 2  models:
1. CERNA- An Email classifer using zero shot prompt classification and Gradio UI. It Identifies the email into the following given categories such as :transactional,promotional.reminder or spam.
Gives the confidence score as output for the top 5 categories.

2. CRIBA- an AI-Powered Resume Analyzer and Skill Extractor using Python and Gradio. The application automates the process of reading candidate resumes (supporting both PDF and Word formats), utilizes Natural Language Processing (NLP) to extract key structural sentences for a summary, automatically pulls out the top professional skills using Part-of-Speech tagging, and displays everything inside an elegant, modern web interface."
